## 安装

1. **思源集市** —— 打开 **设置 → 集市**，找到「一些设置」直接安装；后续更新也走这里。
2. **发行版下载** —— 从 [Releases](https://github.com/wmy2981/some-settings-siyuan/releases) 下载
   `package.zip`，解压到 `<工作空间>/data/plugins/some-settings-siyuan/`，让 `plugin.json` 直接躺在这个目录下，
   然后重启思源。
3. **自行编译** —— 克隆仓库后 `npm install`，再 `npm run build`（需要 Node 24 及以上）；构建产物里有
   `package.zip` 和扁平的 `dist/`，把其中任一个解压到同一个目录即可。

然后打开 **设置 → 集市 → 已下载 → 一些设置 → 设置**，这是唯一的入口 —— 插件不在顶栏、状态栏、
停靠栏注册任何按钮。

## 注意事项

* 设置改完即写入该功能自己的配置文件，面板里没有保存按钮；直接关掉面板也不会丢改动。
* 面板会记住关闭时的页签，下次打开直接回到那一页；该页签已不可用时回到第一个页签。
* 没有单项重置：要恢复某一项，导出配置改好再导入，或直接清除全部。
* 两个重连功能都会重载前端；笔记内容在内核里随时落盘，重载不丢。
* 详细日志默认关闭：控制台里只有一行加载提示，在「插件自身」页签打开后，才会把每个事件按
  INFO / WARN / ERROR 打成一行，并带上功能 id。
* 控制台日志查看器只从它自己的开关打开那一刻开始收集，插件加载期的日志抓不到。
* 移动端行内代码复制按钮按光标位置判定，只复制可见文本。
* 书签跳转只接管整篇文档书签上的干净左键单击。
* 录音浮窗只换界面：思源的录音器没有暂停，所以只提供停止。
* 资源信息直接落在右键菜单里，且只对工作区资源（`assets/…`）生效。
* 代码片段高亮依赖思源自己的 highlight.js，加载不出来就退回纯文本。
* 导入、导出与清除都针对存储目录（`data/storage/petal/some-settings-siyuan`）下的全部配置文件。
* 集市包自定义图标只改本机显示并随思源同步，清除本插件配置不会删掉它们。
* 「智能体工具调用显示细节」只读面板已收到的响应，对不上的调用不显示参数。
* 「智能体回车发送」会盖掉默认的「智能体发送」快捷键。

# 一些设置

> 一批**可独立启停**的思源增强功能：每个设置项都能单独启用、禁用或隐藏。

* 最低思源版本：`3.8.6-alpha.4`
* 适用环境：桌面端、移动端、桌面窗口、浏览器；后端不限
* 只读 / 发布模式下本插件不生效

## 开始使用

打开方式：**设置 → 集市 → 已下载 → 一些设置 → 设置**，这是唯一的入口 —— 插件不在顶栏、状态栏、
停靠栏注册任何按钮。

面板里的每一项都以一个开关开头，**默认全部关闭**，按需逐项打开。改完点「保存」，点「取消」则全部丢弃，
有未保存的改动时关闭会先确认。关掉某个功能会把它**完整卸载**（样式、监听、注入的节点全部撤掉），
不需要重载插件；只在单端生效的功能，在另一端的设置面板里不会出现。

## 注意事项

* 面板没有单项重置：要把某一项恢复默认，先导出配置、改好再导入，或用「清除本插件配置」清空全部。
* 两个重连功能都是**重载前端**：思源没有给插件重建主 WebSocket 的入口，探测到内核恢复后就整页重载。笔记内容始终由内核持有并随时落盘，重载不会丢。
* 控制台日志只在开关打开后才开始收集，插件加载阶段和打开之前的日志不会被记录。要抓启动期的问题，先打开开关再复现。
* 行内代码复制按钮的「悬浮显示」在移动端按**光标位置**判定（移动端没有 hover），点按钮也不会抢走编辑区焦点。复制的是**可见文本**：零宽标记被剥掉，不换行空格换成普通空格。
* 书签跳转只接管**整篇文档**书签上的干净左键单击；带修饰键的单击和加在块上的书签都保持思源自己的行为。
* 录音浮窗只换界面：权限、MP3 编码、上传与插入音频块仍是思源自己的代码，而它的录音器没有暂停，所以浮窗只提供停止。
* 资源信息行直接落在右键菜单里，不进「插件」子菜单；只有工作区资源（`assets/…`）有文件大小与修改时间。
* 「代码片段编辑区高亮」依赖思源自己的 highlight.js；它加载不出来时插件会拆掉高亮层，回到纯文本，不会留下看不见字的输入框。
* 「插件配置导入导出」与「清除本插件配置」针对存储目录（`data/storage/petal/some-settings-siyuan`）下的**全部配置文件**。
* 「集市包自定义图标」的图片保存在存储目录的 `icons/` 下（`作者__包名.扩展名`），只改本机显示并随思源同步；保存图标会自动开启本功能；「清除本插件配置」不删这些图片，要撤销某一张用图标管理窗口的「恢复默认」。
* 「智能体工具调用显示细节」只读**面板已经收到的响应** —— 本轮的事件流与面板自己请求的两份存档响应 —— 不额外发请求。两条路都对不上的调用宁可不显示，也不显示错的参数。
* 「智能体回车发送」把 Enter 改成发送，换行挪到 Ctrl+Enter / Shift+Enter（macOS 上是 Cmd+Enter），会**盖掉默认的「智能体发送」快捷键**。
